# Prompt для завершения задачи / handoff

Перед тем как завершить текущую Arena-сессию:

1. Проверь git diff и убедись, что в нём нет случайных/несвязанных изменений.
2. Проверь фактический результат и запусти доступные тесты/сборки.
3. Не заявляй о тесте, который не запускался. Если Unreal Editor/Build Tools недоступны, укажи NOT RUN и перечисли ручные шаги.
4. Обнови затронутые системные спецификации.
5. Обнови Docs/03_CURRENT_STATUS.md по фактическим данным.
6. Обнови Docs/02_DESIGN_DECISIONS.md только если есть новое решение; новые предложения оставляй PROPOSED, не утверждай их за пользователя.
7. Обнови Docs/04_OPEN_QUESTIONS.md, если возникли нерешённые вопросы.
8. Добавь запись в Docs/06_CHANGELOG.md.
9. Перезапиши Docs/07_HANDOFF.md: branch/commit, цель, изменённые файлы, что проверено, что не проверено, известные проблемы, точный следующий шаг.
10. Проверь, что все эти документы включены в diff до commit/push/PR.
11. Создай один PR для этой Arena-сессии; не сливай его.

В отчёте не используй фразы «всё готово», если остались NOT RUN, ошибки или незакрытые критерии. Укажи их явно.

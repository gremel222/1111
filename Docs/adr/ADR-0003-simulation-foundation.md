# ADR-0003 — Основа симуляции и первый UE-прототип

- **Дата:** 2026-11-03.
- **Контекст:** владелец разрешил начать разработку в текущем репозитории; Windows, UE 5.8 и Visual Studio установлены у владельца. В Arena UE недоступен.

## Подтверждено владельцем

- **U-021 / C-006:** один неизменяемый Battle Snapshot на такт после обновления текущих событий/действий и непосредственно перед DecisionPoint. CONFIRMED_BY_USER.
- **U-022 / C-008:** если ни одно правило не подошло, резервное поведение зависит от роли героя. CONFIRMED_BY_USER. Конкретные алгоритмы ролей не выдавать за прямое утверждение пользователя.

## Проектная основа

- Новый исходный каркас `CodexOfRules.uproject`, EngineAssociation `5.8`, один runtime-модуль.
- SimulationCore — обычный C++ без Unreal-заголовков внутри того же модуля; отдельный native test harness компилирует те же исходники.
- UE-адаптер накапливает время и вызывает фиксированные такты; кадровая частота не меняет правила.
- Первый испытательный сценарий: 2 героя против 3 противников, две сетки 3×3. Полноценный отряд игры остаётся 4 героя (U-015).
- Никаких выдуманных `.uasset`: временная арена использует стандартные примитивы UE; карту владелец создаёт в редакторе.

## Предлагаемые алгоритмы первого прототипа — PROPOSED

- **R-014, Защитник:** доступная защита себя → доступная базовая атака → явный пропуск с причиной.
- **R-015, Лекарь:** лечение наиболее раненого доступного союзника → доступная базовая атака → явный пропуск с причиной.
- Никакого скрытого ожидания или бесконечного повтора. Резерв не создаёт новых способностей.

## Границы

Не реализуются пока: полный каталог блоков, граф/сценарии, перемещение, статусы, телеграфы, приказы, сохранения, replay-файлы, финальный UI и арт.
UE build/editor проверяются на компьютере владельца; native tests не доказывают UE-сборку.

## Последствия

C-006 закрыт подтверждением. C-008 закрыт в части направления, но алгоритмы R-014/R-015 требуют проверки и утверждения. O-020 закрыт для текущего репозитория: разрешено создавать новый каркас; наличие внешнего проекта владельца не отрицается.

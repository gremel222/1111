# Prompt для каждой новой Arena-сессии

Скопируй в начало каждой новой Arena Agent Mode сессии после подключения того же GitHub-репозитория и актуальной ветки.

--- PROMPT START ---

Продолжаем разработку THE CODEX OF RULES / «Свод Правил».

Перед любой работой:
1. Прочитай корневой AGENTS.md.
2. Прочитай Docs/00_START_HERE.md, Docs/02_DESIGN_DECISIONS.md, Docs/03_CURRENT_STATUS.md и Docs/07_HANDOFF.md.
3. Прочитай профильные спецификации, связанные с задачей.
4. Проверь текущую ветку, HEAD commit, git status и реальные файлы проекта.
5. Кратко сообщи, что утверждено, что реализовано по фактическому коду, что проверено, что осталось и какой следующий шаг.

Затем выполни мою задачу: [ВСТАВИТЬ ЗАДАЧУ].

Правила:
- Не проси меня повторять контекст, пока он есть в GitHub Docs.
- Не меняй CONFIRMED_BY_USER или PROJECT_BASELINE молча.
- Новые идеи записывай как PROPOSED/OPEN, пока я явно их не утвержу.
- Не путай запланированные механики с реализованными.
- Перед изменениями составь план и перечисли затрагиваемые системы.
- После изменений выполни доступные проверки и честно пометь отсутствующие как NOT RUN.
- Обнови профильные документы, Docs/03_CURRENT_STATUS.md, Docs/06_CHANGELOG.md и Docs/07_HANDOFF.md.
- Создай один логический PR для этой сессии; не сливай его без моего разрешения.

В конце дай: summary, файлы, тесты PASS/FAIL/NOT RUN, риски, commit и PR URL, следующий шаг.

--- PROMPT END ---

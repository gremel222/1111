# Дорожная карта разработки

План ориентирован на проверку главного игрового цикла, а не на раннее
производство всего контента.

## Phase 0 — Memory + repository audit
- Установить проектную память в GitHub — выполнено ранее.
- Проверить структуру подключённого репозитория — выполнено 2026-11-03: UE-проекта нет.
- Составить техническую карту `IMPLEMENTED / PARTIAL / NOT IMPLEMENTED / BLOCKED` — для подключённого репозитория выполнена в [`08_PHASE0_AUDIT.md`](08_PHASE0_AUDIT.md).
- Проверить доступность UE Editor/toolchain в Arena sandbox — выполнены проверки окружения; UE toolchain не обнаружен.
- Получить существующий UE5.8-проект либо согласовать создание нового каркаса — O-020, BLOCKED до решения владельца.

**Gate:** исходное состояние подтверждено фактами из репозитория. Для подключённой документационной базы это выполнено; аудит внешнего игрового проекта и вся Phase 0 ещё не закрыты.

Нумерация Phase здесь — операционный план; её не следует смешивать с концептуальными этапами паспорта §21.2. Сопоставление предложено в C-005 и ждёт согласования.

## Сквозной арт-трек — рисованное направление

- U-019/U-020 подтверждены: рисованный мир, предметы и герои вместо pixel art; акварельная карта и портреты сохранены; атмосфера меняется по регионам.
- Ориентир: [`09_ART_DIRECTION.md`](09_ART_DIRECTION.md), референс `Docs/references/art/ART-REF-0001.png`, ADR-0002.
- До массового производства предлагается небольшой оригинальный арт-тест: окружение, герой, враг и два варианта атмосферы (R-013, PROPOSED). Технический подход 2D/3D и параметры рисунка открыты (O-022).
- Phase 1 может использовать временные обозначения и не блокируется отсутствием финального арта. К Phase 3 проверяется читаемость фигур/телеграфов, к Phase 4 — согласованность светлых и мрачных зон одного региона. Это предлагаемые проверки, не новые подтверждённые объёмы контента.
- Старый пиксельный бриф — история, не задание для нового производства. Права на сам предоставленный референс не установлены (O-023).

## Phase 1 — AI core prototype
- 2 героя, 2–3 противника, тестовая арена.
- Фиксированный такт, Battle Snapshot, стабильный порядок обработки.
- 8–12 условий/действий и приоритетные карточки правил.
- Доступность действия, коды причин, классовый резерв.
- Обычный журнал и debug.

**Gate:** одинаковые входные данные дают воспроизводимый выбор AI; герой
не зависает, если все правила недоступны.

## Phase 2 — Hybrid editor vertical slice
- Карточки правил.
- Составные условия AND/OR/NOT.
- Сценарии и ограниченные последовательности.
- Граф-режим на единой модели программы.
- Проверка совместимости, undo/redo, шаблоны и сохранение программы.

**Gate:** программа не теряет данные при смене представления; редактор
объясняет ошибки.

## Phase 3 — Combat vertical slice
- 4 героя, 3–6 типов врагов, статусы, способности, позиции 3×3.
- Приказы, телеграфы боссов, поражение и ранения.
- Replay с seed, исходным состоянием и командами игрока.

**Gate:** игрок может отладить проигрыш и изменить результат через
программу.

## Phase 4 — One-region playable slice
- Одно поселение, маршруты, 5–7 локаций, задания, один босс/сюжетная
  угроза.
- Базовый караван, снабжение, ремонт, лагерь.
- Один фрагмент Сводов и сюжетная арка.

**Gate:** полный короткий игровой цикл работает от подготовки до
возвращения.

## Phase 5 — Economy and offline services
- Региональные рынки, крафт, NPC маршрутные службы.
- Отдельная упрощённая офлайн-модель.
- Насыщение рынка, затраты и защита от softlock.

**Gate:** нет бесплатной инфляции и безвыходных состояний.

## Phase 6 — Content production / release
- Расширять героев, регионы, способности и сюжет только после проверки
  инструментов.
- Базовая коммерческая цель меньше полной мечты из паспорта.
- Отдельно оценить достижения, коллекции и монетизацию.

## Phase 7 — Future online roadmap (long-term; not part of v1.0)

Пользователь подтвердил все три направления будущего Multiplayer:
кооператив, асинхронное взаимодействие игроков и общий онлайн-мир. Это
долгосрочная цель, а не обещание реализовать всё одновременно.

- **Gate 7A — online services / asynchronous:** после стабильного
  офлайн-релиза исследовать необязательные аккаунты/облачные
  сохранения, обмен AI-шаблонами, асинхронные испытания и рейтинги.
- **Gate 7B — co-op prototype:** отдельный прототип сетевой PvE-экспедиции;
  определить число игроков, контроль героев, общий караван, паузу/скорость,
  сохранение/дисконнекты и авторитетную симуляцию.
- **Gate 7C — shared online world:** только после оценки спроса, стоимости
  и работы кооператива исследовать постоянные общие зоны/экономику/социальные
  функции. Не предполагать MMO-масштаб без отдельного решения.
- PvP не подтверждён и остаётся отдельным открытым вопросом.
- Перечисленная последовательность — предлагаемая стратегия разработки,
  не обязательство/срок поставки.

**Жёсткая граница:** Phase 0–6 и первая версия игры не должны требовать
интернета, учётной записи или серверной доступности. Не реализовывать
Multiplayer/репликацию в v1.0.

# Дорожная карта разработки

План ориентирован на проверку главного игрового цикла, а не на раннее производство всего контента.

## Phase 0 — Memory + repository audit
- Установить проектную память в GitHub.
- Проверить структуру UE5.8-репозитория и существующие модули.
- Составить техническую карту `IMPLEMENTED / PARTIAL / MISSING / BLOCKED`.
- Проверить доступность UE Editor/toolchain в Arena sandbox.

**Gate:** исходное состояние подтверждено фактами из репозитория.

## Phase 1 — AI core prototype
- 2 героя, 2–3 противника, тестовая арена.
- Фиксированный такт, Battle Snapshot, стабильный порядок обработки.
- 8–12 условий/действий и приоритетные карточки правил.
- Доступность действия, коды причин, классовый резерв.
- Обычный журнал и debug.

**Gate:** одинаковые входные данные дают воспроизводимый выбор AI; герой не зависает, если все правила недоступны.

## Phase 2 — Hybrid editor vertical slice
- Карточки правил.
- Составные условия AND/OR/NOT.
- Сценарии и ограниченные последовательности.
- Граф-режим на единой модели программы.
- Проверка совместимости, undo/redo, шаблоны и сохранение программы.

**Gate:** программа не теряет данные при смене представления; редактор объясняет ошибки.

## Phase 3 — Combat vertical slice
- 4 героя, 3–6 типов врагов, статусы, способности, позиции 3×3.
- Приказы, телеграфы боссов, поражение и ранения.
- Replay с seed, исходным состоянием и командами игрока.

**Gate:** игрок может отладить проигрыш и изменить результат через программу.

## Phase 4 — One-region playable slice
- Одно поселение, маршруты, 5–7 локаций, задания, один босс/сюжетная угроза.
- Базовый караван, снабжение, ремонт, лагерь.
- Один фрагмент Сводов и сюжетная арка.

**Gate:** полный короткий игровой цикл работает от подготовки до возвращения.

## Phase 5 — Economy and offline services
- Региональные рынки, крафт, NPC маршрутные службы.
- Отдельная упрощённая офлайн-модель.
- Насыщение рынка, затраты и защита от softlock.

**Gate:** нет бесплатной инфляции и безвыходных состояний.

## Phase 6 — Content production / release
- Расширять героев, регионы, способности и сюжет только после проверки инструментов.
- Базовая коммерческая цель меньше полной мечты из паспорта.
- Отдельно оценить достижения, коллекции и монетизацию.

## Phase 7 — Online/server roadmap
- Только после стабильной offline-first одиночной игры.
- Сначала прототип сервисов/облачных сохранений/обмена AI-шаблонами.
- Возможный кооператив на двоих — отдельное решение и отдельный бюджет.

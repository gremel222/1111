# История изменений проектной документации

## 2026-11-03 — Решения по пяти открытым вопросам (паспорт v1.3.1)
- Баланс: разделены формулы/правила системы и числовые коэффициенты;
  баланс хранится в Data Assets/Data Tables/Curve Tables; список
  прототипных проверок зафиксирован в `01_GAME_PASSPORT.md` §26.1.0.
- Редактор AI: утверждена общая структура окна (верх/лево/центр/право/низ)
  и очерёдность режимов (сначала карточки правил, затем сценарии и граф);
  финальный UI отложен до интерактивного прототипа (§26.2.1).
- Монетизация: модель Premium one-time остаётся `PROPOSED` (R-003);
  реализация торговли/DLC отложена до коммерческого релиза (§26.3).
- Достижения/коллекции: включены в концепцию через Архив путешественника
  с семью коллекциями и примерами условий; полноценная реализация — после
  основного игрового цикла (§26.4).
- Сервер/Multiplayer: создан ADR-0001 — три направления подтверждены как
  долгосрочные (кооператив, асинхронное взаимодействие, общий онлайн-мир);
  v1.0 остаётся offline-first; формат Multiplayer — открыт
  (§26.5, `Docs/adr/ADR-0001-future-multiplayer-direction.md`).
- Реестр решений: добавлены U-018, P-013, R-009–R-012; R-005 переформулирован
  (детали кооператива OPEN); R-011 — предлагаемая, но не утверждённая
  очерёдность онлайн-фаз.
- Roadmap: уточнены Phase 0–6 и добавлена Phase 7 — будущие онлайн-фазы
  с Gate 7A/7B/7C; PvP остаётся открытым.
- Статус реализации Unreal Engine: остаётся NOT VERIFIED; в этом
  репозитории нет UE-проекта (только документация).

## 2026-11-03 — Memory bootstrap package
- Добавлена корневая инструкция `AGENTS.md` для устойчивого контекста
  AI-агентов.
- Добавлена структура `Docs/` как источник проектной памяти.
- Канонический паспорт v1.3 включён в Markdown; DOCX/PDF добавлены как
  экспорты.
- Разделены подтверждённые решения, проектная база, предложения и
  открытые параметры.
- Зафиксирован Arena workflow: отдельная копия репозитория на сессию,
  один PR на чат, обязательная проверка и обновление HANDOFF до merge.
- Статус реализации Unreal Engine оставлен `NOT VERIFIED` до аудита
  реального репозитория.

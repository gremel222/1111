# Content

В этой папке пока нет игровых `.uasset` или `.umap`.

Первая тестовая арена собирается C++-адаптером из стандартных примитивов движка.
Это временная визуализация, не финальный рисованный стиль U-019/U-020.

Инструкция первого открытия и создания тестовой карты:
[`../Docs/10_WINDOWS_UE_SETUP.md`](../Docs/10_WINDOWS_UE_SETUP.md).

Не добавлять сюда `Binaries`, `Intermediate`, `Saved`, `DerivedDataCache`.
Оригинальные игровые assets появятся отдельной задачей после проверки ядра.
